# SQL Business Reporting Projects

This repository contains SQL projects demonstrating business reporting, inventory analysis, subscription analytics, and product data validation.

## Projects

### Product Data Validation
Identifies purchased products that exist in ERP systems but are missing from ecommerce systems.

Skills:
- JOINs
- LEFT JOIN logic
- Data validation
- Cross-system reconciliation

### Subscription Inventory Analysis
Connects active subscriptions to inventory and product information.

Skills:
- CTEs
- Window Functions
- CASE statements
- Multi-table joins

### Kit Inventory Reporting
Calculates available inventory for kits based on component quantities.

Skills:
- Aggregation
- GROUP BY
- Inventory analysis
